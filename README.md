# 结绳 · Knotted

SillyTavern 剧情记忆扩展。自动总结剧情，分代压缩记忆，让长对话不再撑爆上下文。

## 特性

- **注入式存储**：总结存在聊天元数据里，通过 `setExtensionPrompt` 注入，不占用世界书
- **分代压缩**：记忆过长时自动压缩，压缩块可再压缩，带保底字数防止老剧情被榨干
- **事件脉络**：每次总结后读取完整旧脉络与本次总结，用同一个 API 编织极简时间线；只追加新节点，不让模型改写旧节点
- **滑动窗口隐藏**：已总结的楼层自动隐藏以节省 token，末尾若干楼保留可见；删楼回退时自动恢复
- **手动编辑**：记忆内容可随时查看和修改
- **导出备份**：一键导出到世界书条目（默认禁用，仅作备份）
- **降级兼容**：环境不支持注入式存储时自动退回世界书模式

## 兼容性

单文件原生 JavaScript，无构建流程。已在以下环境测试：

- Android Termux
- iOS 云酒馆
- SillyTavern 1.14 – 1.18

## 安装

SillyTavern → 扩展 → 安装扩展 → 粘贴本仓库地址。

## 事件脉络（2.2.0）

每轮总结完成并保存后，再调用一次同一 API / 模型生成脉络。第二次请求只读取「已有脉络 + 最新总结」，不重复发送所有旧总结。通常只追加一个 `[时间] 事件` 节点；首次没有脉络时可生成多个节点。脉络失败会提示，已经保存的总结不受影响。

在「记忆与压缩」里查看和编辑「事件脉络」，一行一个节点，点击「保存脉络」生效。手动保存保留你填写的非空行，不要求模型输出格式。保存为全空可清空脉络。等待中的模型结果不会覆盖手动保存的内容。

「重建脉络」会清空当前脉络，按楼层先后逐段读取现有总结，上一段完成后再处理下一段。每段调用一次 API，中途失败会停止并保留已完成的节点；再次重建会从头开始。记忆已压缩时，重建使用现存的压缩段与新总结。世界书模式使用当前聊天、当前总结类型的已启用条目。

节点按聊天保存在 `chat_metadata.autoSummaryAdv_v1.threadNodes`，结构为 `{ id, layerId, text }`。总结段保留稳定 `layerId`，压缩保留来源 ID。重跑相同楼层区间会替换该段及其节点；部分重叠的区间需先删除原段再总结。通过记忆编辑框删除段落、清空记忆或删楼回退时，同步清理对应节点。脉络与总结使用同一个注入块，脉络在前、总结先行提示词及总结在后；世界书模式复用原总结条目。

运行回归检查：`node --test tests/thread.test.cjs`。无需安装依赖或构建。

## 已知问题

- 回退超出压缩块边界时，世界书内容需要手动处理。
