# 结绳 · Knotted

SillyTavern 剧情记忆扩展。自动总结剧情，分代压缩记忆，让长对话不再撑爆上下文。

## 特性

- **注入式存储**：总结存在聊天元数据里，通过 `setExtensionPrompt` 注入，不占用世界书
- **分代压缩**：注入与世界书模式均支持手动/自动压缩，压缩块可再压缩，带保底字数防止老剧情被榨干
- **事件脉络**：每次总结后读取完整旧脉络与本次总结，编织极简时间线；API 配置可跟随总结或独立选择，只追加新节点，不让模型改写旧节点
- **滑动窗口隐藏**：已总结的楼层自动隐藏以节省 token，末尾若干楼保留可见；删楼回退时自动恢复
- **手动编辑**：记忆内容可随时查看和修改
- **导出备份**：一键导出到世界书条目（默认禁用，仅作备份）
- **降级兼容**：环境不支持注入式存储时自动退回世界书模式

## 兼容性

单文件原生 JavaScript，无构建流程。已在以下环境测试：

- Android Termux
- iOS 云酒馆
- SillyTavern 1.14 – 1.18

## 安装

SillyTavern → 扩展 → 安装扩展 → 粘贴本仓库地址。

## 世界书压缩（2.3.0）

世界书模式也可在「压缩 → 记忆与压缩」使用「立即压缩」和「自动压缩」。可独立选择压缩 API 配置档；保鲜段、保底字数、字数阈值与注入模式共用。面板显示世界书的真实段数、正文总字数、楼层和压缩代数，记忆查看框为只读，编辑仍通过世界书内容卡片进行。单次总结后检查自动压缩，批量总结在完成或停止后检查。

只压缩当前聊天、当前小总结/大总结类型的已启用总结，兼容旧版首段没有范围标记的条目。多个总结条目会整理到一个现有条目，其余原条目停用并标记为「压缩前备份」，不删除，重开聊天也不会重新启用。末尾保鲜段与保底段原样保留；保底段和楼层空隙隔开的范围不会跨段合并。重复区间内容不一致或范围重叠时停止并提示整理，避免丢失剧情。压缩保留全部脉络节点及来源关联，后续追加、重建和删除压缩段继续使用这些关联。头部说明仍只放一次。

调用压缩 API 前，把原条目、激活状态和来源关联备份到当前聊天的 `chat_metadata`，与注入模式备份分开。备份失败不发起压缩。API 失败不改世界书，写入部分失败会尝试恢复原条目。「撤销上次压缩」恢复总结和激活状态，保留现在的脉络；若压缩后新增、编辑或删除过总结，撤销会拒绝覆盖这些新内容。备份仅对同一聊天、世界书和总结类型有效，成功撤销后消耗该备份。删除聊天会同时删除压缩备份。

## 记忆头部说明（2.2.1）

世界书与注入模式均只在整份记忆的总结正文前放一次头部说明，有脉络时顺序为「脉络 → 头部说明 → 全部总结」。单次总结、压缩结果和发送给脉络 API 的最新总结均不携带这段说明。

在「接口」页的提示词设置中编辑「记忆头部说明（整份记忆仅一次）」。加载或继续总结时会清理旧总结中完整、独占行的当前说明和默认说明；正文中的行内引用保留。世界书有多个启用的总结条目时，只在当前聊天、当前总结类型的最新条目保留统一前缀。注入模式在构造提示词时去重，后续保存也会清理存储的总结正文。

## 事件脉络（2.2.0）

每轮总结完成并保存后，再调用一次 API 生成脉络。第二次请求只读取「已有脉络 + 最新总结」，不重复发送所有旧总结。通常只追加一个 `[时间] 事件` 节点；首次没有脉络时可生成多个节点。脉络失败会提示，已经保存的总结不受影响。

「脉络使用的 API 配置档」默认跟随本轮总结的 API / 模型，也可选择「接口」页创建的其他配置档。自动编织与重建均使用此选择；总结、压缩的 API 选择独立。配置档删除后自动回退到跟随总结；所选配置未填地址或模型时会提示，重建不会清空已有脉络。每轮任务开始时固定本轮配置，修改选择在下次任务生效。

在「记忆与压缩」里查看和编辑「事件脉络」，一行一个节点，点击「保存脉络」生效。手动保存保留你填写的非空行，不要求模型输出格式。保存为全空可清空脉络。等待中的模型结果不会覆盖手动保存的内容。

「重建脉络」会清空当前脉络，按楼层先后逐段读取现有总结，上一段完成后再处理下一段。每段调用一次 API，中途失败会停止并保留已完成的节点；再次重建会从头开始。记忆已压缩时，重建使用现存的压缩段与新总结。世界书模式使用当前聊天、当前总结类型的已启用条目。

节点按聊天保存在 `chat_metadata.autoSummaryAdv_v1.threadNodes`，结构为 `{ id, layerId, text }`。总结段保留稳定 `layerId`，压缩保留来源 ID。重跑相同楼层区间会替换该段及其节点；部分重叠的区间需先删除原段再总结。通过记忆编辑框删除段落、清空记忆或删楼回退时，同步清理对应节点。脉络与总结使用同一个注入块，脉络在前、总结先行提示词及总结在后；世界书模式复用原总结条目。

运行回归检查：`node --test tests/thread.test.cjs`。无需安装依赖或构建。

## 已知问题

- 记忆跟随聊天存储，删除聊天即删除记忆。重要内容请用「导出到世界书」备份。
- 回退超出压缩块边界时，世界书内容需要手动处理。
- 世界书压缩和脉络需环境能保存聊天元数据；无法保存备份时会停止压缩。酒馆/API 回归检查使用模拟接口，未覆盖所有实际部署环境。
